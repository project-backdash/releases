# Project Backdash releases

Project Backdash brings Tekken 5: Dark Resurrection Online to PC with rollback netcode, lobbies, Ranked, spectating,
replays and a modern Practice mode. You play with your own copy of the game.

## Download

- **Installer:** the newest release on this page, or [backdash.gg](https://backdash.gg). Both are the same file; check it
  against the SHA-256 in the release notes if you like.
- It installs for your Windows user only (no admin rights) and updates itself.

Requirements: Windows 10 or 11 (64-bit) and your own North American PSN copy of the game with its licence (.rap).

## Source

The emulator, with every in-game Project Backdash feature, is open source under the GNU GPL v2:
[project-backdash/rpcs3](https://github.com/project-backdash/rpcs3). Each release there has the source and the emulator
build that shipped in that version.
